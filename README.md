# Motion-Aware Future Frame Prediction with Bezier Trajectory Regularization

This repository contains an extended version of the Future Frame Prediction (FFP)
framework for video anomaly detection.

## Key Contributions
- Motion-aware generator design
- Temporal consistency enforcement
- Bezier curve–based trajectory regularization

## Dataset
- UCSD Ped2

## Notes
This repository is developed as part of a Master's thesis and is designed
to be compared against the original FFP baseline under identical settings.
